# Digital Library & Book Recommendation System

## Overview
A lightweight Python-based library management and recommendation engine developed for the **CSE1021 - Introduction to Problem Solving and Programming** course. This system relies strictly on standard Python data structures (Lists, Dictionaries, Sets, Tuples) to manage records and compute recommendation metrics using Set Similarity algorithms.

## Features
- **Book & User Management:** Add books, register users, track borrowing state.
- **Search Engine:** Query books by title or author keywords.
- **Recommendation Engine:** Uses Jaccard Similarity on Sets to suggest relevant books based on previous borrowing preferences.
- **Input Validation:** Error-handling routines ensuring system stability on user entry errors.

## Technologies Used
- **Language:** Python 3.8+
- **Modules Used:** Core standard library (`sys`, `os`)
