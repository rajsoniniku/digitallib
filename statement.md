# Problem Statement: Digital Library & Book Recommendation System

## Problem Statement
Traditional library catalogs lack personalized guidance, making it tedious for readers to discover new books aligned with their reading interests. Furthermore, small academic or community libraries require lightweight, low-overhead digital systems to manage catalog books, monitor borrowing status, and maintain user interest histories without heavy external software dependencies.

## Scope of Project
The scope of this project includes:
1. Core catalog and user management operations (CRUD).
2. Linear search algorithms for quick book title/author queries.
3. An automated recommendation engine utilizing Set operations (Jaccard similarity index) to match user interest history against unread books.
4. Terminal UI execution with robust input sanitization and validation logic.

## Target Users
- Library Administrators / Librarians managing book inventories.
- Library Members / Students searching for books and seeking reading recommendations.

## High-Level Features
- Dynamic Book & User Registration
- Search and Availability Checker
- Automated Borrowing & Return Pipeline
- Tag-based Content Filter Recommendation Engine
